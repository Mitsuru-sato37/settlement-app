# settlement-app

仲間内の立替・ゲーム収支を、ひとりが入力して同じ画面で確認する精算アプリです。React + TypeScript + Vite 製です。

## 使い方

1. 精算モードを選び、新しい記録を作成します。新規記録は空です。「サンプルを読み込む」は別のサンプル記録を作ります。
2. 参加者を追加し、金額や点数を入力します。通常精算では明細ごとに支払者・対象者を選びます。
3. 収支が一致し、入力に問題がなければ「誰が誰に何円払うか」が表示されます。差額・入力エラーがある場合、送金は確定表示されません。
4. 記録は使用した端末・ブラウザの `localStorage` に保存されます。ブラウザのデータ消去やシークレットモードでは失われるため、定期的に JSON を書き出してください。JSON 読み込みでは全記録が置き換わり、確認画面が出ます。

## 起動・検証

```bash
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

## 対応モード

- 通常精算: 明細の金額、支払者、対象者を編集し、1 円の端数まで分けて送金を表示します。
- ポーカー: 全員の最終収支を入力し、合計 0 円で送金を表示します。
- 麻雀: 三麻・四麻を選び、開始点、返し点、レート、ウマ、チップを設定して半荘ごとに記録します。オカは独立した入力項目を設けず、`(返し点 - 開始点) × 人数` をトップに自動加算します。累計を最上部に表示します。
- ノリ打ち: 投資と回収の全体損益を均等に分け、送金を表示します。
- 全額払いルーレット: 各人の候補額に比例した色の面積と確率で抽選します。当選者が合計額を全額支払います。

初版はアカウント、共同編集、サーバー同期、端末間共有、実際の決済、ポーカーのチップ購入・換金履歴には対応しません。「保存済み」はこのブラウザへの書き込み成功を示し、バックアップ完了を意味しません。
